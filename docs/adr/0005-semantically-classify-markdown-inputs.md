# Semantically classify Markdown inputs

The source root represents a format-agnostic Input Corpus that initially discovers PDF and Markdown files recursively. A root `index.md` declaring `okf_version: "0.2"` signals import intent, but the entire marked Bundle must pass Portable OKF Validation before any of its valid Concepts are imported; ordinary Markdown evidence therefore lives outside marked boundaries. The marker is not a conformance requirement, so Portable OKF Validation still accepts conformant Bundles without it. Each marked root forms an independent boundary, nested content belongs to its nearest marked ancestor, and reserved `index.md` and `log.md` files are metadata rather than Concepts. Imported types are preserved even when they fall outside the agent producer's controlled vocabulary, avoiding both accidental partial import and needless re-synthesis of intentional OKF knowledge.
