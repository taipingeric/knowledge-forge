# Join claims through Source Reference IDs

Knowledge Forge distinguishes a durable document-level Source Identity from each Concept-local Source Reference ID. For generated Concepts, every material claim footnote label exactly equals the `id` of its `sources` entry, whose `resource` identifies the underlying Knowledge Source and whose typed locator records PDF pages or a Markdown heading path and block hash. The reference ID derives deterministically from Source Identity and structural address without including content hashes; document and block hashes independently detect changed evidence while the citation join remains stable. This follows the OKF join convention without sacrificing precise evidence location, while valid citations in Imported Concepts are preserved unchanged.
