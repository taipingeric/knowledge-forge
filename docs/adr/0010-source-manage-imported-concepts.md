# Source-manage Imported Concepts

An Imported Concept keeps its original Bundle-relative Concept ID and is source-managed rather than agent-owned or overwritten. Its initial UTF-8 Markdown bytes and exact Imported Baseline are preserved; deterministic serialization is permitted only when a later three-way merge changes that document. Knowledge Forge reconciles the baseline, current human-curated Concept, and later source version: non-overlapping changes merge, overlapping structural blocks conflict atomically, and collisions between imported or planned Concept IDs fail instead of being guessed or namespaced implicitly. A first import that meets a Human-owned Concept has no common baseline and therefore creates a Reconciliation Conflict: `keep-human` records a conditional exclusion for that import version, `use-source` adopts the Imported Concept, and `manual` establishes the reviewed initial Imported Baseline. When an imported source disappears, an unchanged import is removed, while an import with a Human Delta requires reconciliation: `keep-human` converts it to a Human-owned Concept and `use-source` accepts deletion. Imported trust signals remain intact but are recorded as external assertions rather than local Verification Events.
